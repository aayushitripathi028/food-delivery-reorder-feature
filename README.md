# Reorder Feature for Food Delivery App

## Overview

This repository contains a UX/Product design concept for implementing a **Reorder feature in a food delivery application**.

The feature allows users to quickly reorder previously purchased items without going through the entire browsing process again, improving convenience and increasing repeat purchases.

---

## Problem Statement

Users who frequently order the same food items often have to repeat the entire ordering process every time.

This increases friction and slows down the ordering experience.

A reorder feature can simplify this process by allowing users to quickly select previously ordered items and place the order again with minimal effort.

---

## Proposed Solution

The solution introduces a **dedicated Reorder flow** within the food delivery app that allows users to:

* View previously ordered items
* Quickly add them to cart
* Modify quantity or add-ons
* Proceed to checkout
* Complete payment with saved payment methods

---

## User Flow

The reorder journey includes the following steps:

1. Home Page
2. Reorder Page
3. Item Selection
4. Add-ons and Customization
5. Checkout / Order Summary
6. Payment Options
7. Payment Processing
8. Order Confirmation

The UI screens illustrate how users move from selecting a previous order to completing the payment.
